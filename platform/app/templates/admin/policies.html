Policies & Access Grants

Define who can access what, under which conditions
1 · Policies
Rules evaluated at SSH cert request time. Allow/Deny with conditions (device status, environment, IP). Lower priority number = evaluated first.
2 · Access Grants
Entitlements that give a user or group access to a server scope as specific Unix principals (e.g. ubuntu, root). Grants are enforced by policies.
How they interact
At cert request time: user must have an Access Grant for the target server and an enabled Allow policy must match. A matching Deny policy overrides any allow.
