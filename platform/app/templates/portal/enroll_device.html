Enroll a New Device

Register your device to use Keyward SSH access
1
Configure the Agent

Install the Keyward agent and point it to this platform. Add this URL to your agent configuration:

https://{{ request.host }}/

Download the agent from the releases page or via your IT administrator.

2
Enroll from Your Device

Run the enrollment command on the device you want to enroll. Sign in with your account:

keyward-agent enroll

macOS / Windows: Use the system tray icon → Enroll Device.
Linux: Run the command above in a terminal.

3
Approve in Browser

After running the enrollment command, you'll receive a short code. Enter it here to approve your device.
