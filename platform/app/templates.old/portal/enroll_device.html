Step 2 — Enroll Device
Register this device and create a keyward. You will receive a one-time code to approve below.
Terminal
keyward-agent enroll --name $(hostname) --platform linux
Replace linux with macos or windows as appropriate.
Step 3 — Approve in Browser
After running the enroll command, visit the approval page with the one-time code shown in the terminal.
